# CriticalCellSpacing
1. File Preparation

  Place the .mph file and the two associated MATLAB files in the same folder.
  
2. Launching the Simulation

  Open COMSOL Multiphysics 6.1.
  
  Run the .mph file directly from within COMSOL.
  
3. Result Analysis

  The simulation will allow you to investigate the effect of cell spacing on cell activation and communication.
